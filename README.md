# SSN ACM-W Student Chapter

The website for the SSN ACM-W Student Chapter, currently under development.

## Stack

Next.js App Router, React, TypeScript, Tailwind CSS, ESLint, and npm.

## Getting started

Requires Node.js 20.9 or later and npm.

```bash
npm ci
npm run dev
```

Open http://localhost:3000. To create a production build, run `npm run build`.

## Structure

- `src/app/page.tsx` — homepage
- `src/app/layout.tsx` — root layout and metadata
- `src/app/globals.css` — global styles and Tailwind import
